# Password Generator

## Description
This Python project generates secure random passwords based on the user's chosen length and character types.

## Features
- Requires a minimum password length of 8 characters.
- Allows users to select uppercase letters, lowercase letters, numbers, and symbols.
- Uses Python's `secrets` module for secure password generation.
- Validates the password length.
- Requires at least one character type to be selected.
- Allows users to generate another password without restarting.

## Technology
- Python 3
- `secrets` module
- `string` module

## How to Run
Run `main.py` using Python. Enter a password length of at least 8, choose the character types, and follow the prompts.
