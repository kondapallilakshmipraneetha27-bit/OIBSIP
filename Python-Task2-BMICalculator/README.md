# BMI Calculator

## Project Overview
This Python project calculates Body Mass Index (BMI) using a person's weight in kilograms and height in meters. It displays the BMI value and a category.

## Features
- Accepts weight and height from the user.
- Checks that the values are positive.
- Calculates BMI using weight / (height × height).
- Displays the BMI rounded to two decimal places.
- Displays a BMI category.
- Handles invalid numeric input.

## Technologies Used
- Python

## How to Run
Run `main.py` in Python and enter your weight in kilograms and height in meters when prompted.

## Formula
BMI = Weight (kg) / Height (m)²
