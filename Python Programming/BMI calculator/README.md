# BMI Calculator

## Project Description
This is my first Python internship project at Oasis Infobyte. It calculates Body Mass Index (BMI) using weight and height.

## Formula
BMI = Weight / (Height × Height)

## Technologies Used
- Python
- Google Colab

## How to Run
1. Run the Python program.
2. Enter your weight in kilograms.
3. Enter your height in meters.
4. View the calculated BMI.

## Sample Output
BMI Calculator
Enter your weight in kg: 60
Enter your height in meters: 1.6
Your BMI is: 23.44
